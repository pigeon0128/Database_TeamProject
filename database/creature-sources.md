# 도감 정보 출처 정리

도감 따라 그리기 15개 대상의 설명(`creature_profiles.summary`, `creature_facts`)을 공신력 있는 출처에서 확인해 정리했다.
아래 "최종 설명글 안"이 `seeds/content.sql` 과 `migrations/011_creature_sources.sql` 에 들어 있고, 출처는 `creature_sources` 표에 있다.
각 줄의 **[번호]** 는 아래 "출처 목록"의 번호다. 확인 날짜: 2026-10-23.

- **확인됨**: 출처 원문에서 직접 읽고 확인했다.
- **확인 못 함**: 출처를 찾지 못했거나 원문을 열지 못했다. 지어내지 않고 비워 두거나 지금 문구를 빼자고 제안한다.
- "그릴 때 살펴볼 점"(`creature_tips`)은 밑그림 모양을 보고 쓴 안내라서 출처 대상이 아니다.

## 최종 설명글 안 (DB에 넣을 문구)

도감 카드(`CreatureInfo.tsx`)에는 한 줄 소개(`summary`) → 정보 항목(`creature_facts`, 이름: 내용) → 그릴 때 살펴볼 점(그대로 둠) 순서로 보이고, 맨 아래에 **📚 출처** 줄을 새로 붙인다.
