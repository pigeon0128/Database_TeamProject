# 따라 그리기 채점 알고리즘

점수는 흰 선을 얼마나 채웠는지에서 선 밖 침범과 겹쳐 그리기 감점을 뺀 값이며, 그리는 동안 0.12초마다 다시 계산합니다.
모든 계산은 브라우저에서 하고, 완료할 때 최종 점수만 DB(`play_records.similarity_score`)에 저장합니다.

```
점수 = 흰 선 채움% − 회색 침범 감점 − 겹쳐 그리기 감점      (0 ~ 100)
```

밑그림은 따라 그릴 **흰 선**과 그 밖의 **회색 구역**으로 나뉘고, 사용자가 칠한 픽셀을 이 두 구역과 비교합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `traceScore.ts` (이 폴더) | 채점 전체: 흰 선·회색 구역 마스크, 채움, 침범, 겹침 계산 |
| `sceneAssets.ts` (이 폴더) | 장면을 열 때 밑그림을 손질하고 채점 마스크를 한 번 만들어 둠 |
| `strokes.ts` (이 폴더) | 획 데이터 형식, 선 끝 얇게(`taper`) |
| `src/pages/story/useSceneScoring.ts` | 언제 채점할지: 획을 다 그었을 때, 그리는 동안(0.12초마다) |
| `src/components/TracingCanvas.tsx` | 그림판. 획을 그리고, 그리는 중인 획을 채점으로 넘김(`onDrawing`) |
| `src/pages/story/ScoreBar.tsx` | 점수판 표시 |

## 1. 흰 선 채움 (+)

따라 그려야 할 흰 선 픽셀 중 칠한 비율이 그대로 점수가 됩니다 (1% = 1점).

```
흰 선 채움% = 칠한 흰 선 픽셀 수 ÷ 전체 흰 선 픽셀 수 × 100
```

1. 장면을 열 때 밑그림에서 밝기 225 이상인 픽셀을 흰 선으로 표시해 둡니다 (숲속의 노래: 약 5.5만 픽셀).
2. 사용자 캔버스에서 투명도 40 이상인 픽셀을 칠한 것으로 봅니다.
3. 흰 선이면서 칠해진 픽셀 수를 세어 비율을 구합니다.

## 2. 회색 침범 감점 (−)

선 밖(회색 구역)을 칠한 비율에 10을 곱해 깎습니다 (회색 구역 1% 침범 = −10점).

```
침범 감점 = 칠한 회색 구역 픽셀 수 ÷ 전체 회색 구역 픽셀 수 × 100 × 10
```

- 흰 선이 아닌 모든 곳이 회색 구역입니다. 단, 흰 선에서 3픽셀 안쪽은 테두리가 흐려서 침범으로 보지 않습니다.
- 회색 구역(약 140만 픽셀)이 흰 선(약 5.5만 픽셀)보다 약 25배 넓어서, %를 그대로 빼면 감점이 너무 약하므로 10배를 곱합니다.

## 3. 겹쳐 그리기 감점 (−)

이미 칠한 곳을 다시 칠한 비율이 5%를 넘으면, 넘은 1%p마다 1점을 깎습니다.
덧칠, 털선, 문지르기를 따로 구분하지 않고 "이미 칠한 곳을 다시 칠했는가" 하나로 판정합니다.

```
겹침% = 각 픽셀별 덧칠된 횟수의 합 ÷ 각 픽셀별 칠해진 횟수의 합 × 100
겹침 감점 = max(0, 겹침% − 5) × 1
```

- **덧칠된 횟수:** 픽셀이 처음 칠해진 뒤 또 칠해질 때마다 1회 (두 번 칠한 픽셀은 1회, 세 번은 2회)
- **칠해진 횟수:** 처음 1회 + 덧칠된 횟수. 합이 2000보다 작으면 2000으로 나눔
- **예:** 100픽셀을 칠하고, 그중 20픽셀을 한 번 더, 그중 5픽셀을 또 한 번 더 칠하면 25회 ÷ 125회 × 100 = 20%

그린 획을 순서대로 1픽셀 간격의 붓 도장으로 다시 찍으며, 픽셀마다 칠해진 횟수와 덧칠된 횟수를 셉니다.

| 사용자가 한 일 | 판정 조건 | 처리 |
|---|---|---|
| 다른 획으로 같은 곳을 또 그음 (덧칠, 털선 이음매) | 마지막 획 ≠ 지금 획, 그리고 칠해진 횟수 > 0 | 덧칠 +1 |
| 펜을 떼지 않고 왔다 갔다 문지름 | 마지막 획 = 지금 획, 그리고 (지금 위치 − 마지막 위치) > 붓 굵기 × 0.5 | 덧칠 +1 |
| 처음 칠함 | 마지막 획 ≠ 지금 획, 그리고 칠해진 횟수 = 0 | 칠해진 횟수만 +1 |
| 지우개로 지움 | 지우개 획 | 그 픽셀 기록 초기화 (다시 그려도 겹침 아님) |
| 선 밖(회색 구역)을 칠함 | 회색 구역 픽셀 | 세지 않음 (침범 감점이 따로 처리) |

- **위치(지나온 거리):** 획 시작점부터 붓이 지나온 길이입니다. 점과 점 사이 거리 √(dx² + dy²)를 차례로 더해 구합니다.
- **한 번 긋기와 문지르기 구분:** 도장을 1픽셀마다 찍어서 한 번만 그어도 같은 픽셀에 도장이 여러 번 찍힙니다. 그래서 픽셀을 떠났다가 붓 굵기의 절반 이상 더 간 뒤 돌아왔을 때만 겹침으로 셉니다.
- **예시:** 같은 선 두 번 = 겹침 50%, 감점 −45점 · 한 번에 쭉 긋기 = 겹침 0%, 감점 0점

## 4. 실시간 점수 계산

획을 긋는 동안 0.12초마다 그리는 중인 획까지 넣어 채점합니다.
이미 그은 획의 계산 결과는 다시 쓰기 때문에, 획이 100개여도 채점 한 번에 약 9ms입니다 (이전 방식 226ms).

1. 펜이 움직이면 새 점을 획에 붙이고 캔버스에 바로 그립니다.
2. 마지막 채점에서 0.12초가 지났으면 바로 채점하고, 아니면 남은 시간 뒤로 한 번만 예약합니다 (펜이 느려지지 않게).
3. 흰 선 채움과 회색 침범은 캔버스 픽셀을 읽어 계산합니다. 그리는 중인 획도 이미 캔버스에 있어 자동으로 반영됩니다.
4. 겹침은 기록해 둔 결과에 그리는 중인 획만 잠깐 더해 구하고, 바꾼 픽셀을 원래 값으로 되돌립니다.
5. 펜을 떼면 예약된 채점을 취소하고, 완성된 획을 기록에 더해 한 번 더 채점합니다.

| 획 종류 | 처리 |
|---|---|
| 이미 기록에 있는 다 그은 획 | 다시 계산하지 않음 |
| 새로 다 그은 획 | 기록에 한 번만 더함 |
| 그리는 중인 획 | 잠깐 더해 세고 되돌림 (점이 계속 늘어나는 중이라) |
| 되돌리기, 전체 지우기, 이어 그리기 불러오기 | 기록을 지우고 처음부터 다시 셈 |

기록(`overlapStates`)은 브라우저 메모리에만 있고 DB에는 저장하지 않습니다.
새로고침하면 사라지지만 획 목록에서 언제든 다시 만들 수 있어 점수는 달라지지 않습니다.
되돌리기·지우개가 섞인 96가지 경우에서 처음부터 다시 센 결과와 모두 같았습니다.

## 5. 변수

변수 값은 공식으로 나온 것이 아니라, 테스트 획으로 측정하며 조정한 경험값입니다.

| 변수 | 값 | 역할 | 정한 방법 |
|---|---|---|---|
| `WHITE_MIN` | 225 | 이 밝기(0~255) 이상이면 흰 선 | 첫 채점 구현 때 정함, 과정 기록 없음 |
| `PAINT_ALPHA_MIN` | 40 | 이 투명도(0~255) 이상이면 칠한 것으로 봄 | 첫 채점 구현 때 정함, 과정 기록 없음 |
| `GRAY_TOLERANCE` | 3px | 흰 선 주변 이 거리는 침범 아님 | 첫 채점 구현 때 정함, 과정 기록 없음 |
| `GRAY_PENALTY_WEIGHT` | 10 | 회색 침범 1%당 깎는 점수 | 회색 구역이 약 25배 넓어 감점이 약한 것을 보정. 10으로 정한 과정은 기록 없음 |
| `OVERLAP_FREE_PCT` | 5% | 이만큼의 겹침은 봐줌 (이음매, 선이 만나는 곳) | 팀 결정. 10% → 12% → 0% → 5% |
| `OVERLAP_PENALTY_WEIGHT` | 1 | 허용치를 1%p 넘을 때마다 깎는 점수 | 팀 결정. 흰 선 채움(1% = 1점)과 같은 비율 |
| `SELF_RETURN_BRUSH` | 0.5 | 같은 획이 되돌아왔다고 보는 거리 = 붓 굵기 × 0.5 (굵기 6이면 3px) | 테스트. 2배면 지그재그가 19%로만 잡혔고, 0.5배면 67%로 잡히면서 깔끔한 선은 1.5% |
| `OVERLAP_MIN_PASSES` | 2000 | 겹침%의 분모 최솟값. 그리기 시작 직후 값이 튀지 않게 함 | 굵기 6으로 약 285px 분량. 테스트 결과 처음 약 280px에만 작동, 최종 점수 영향 없음. 1000 이하는 효과 없고 4000은 초반 덧칠을 너무 봐줌 |
| `BRUSH_EDGE` | 0.5px | 붓 반지름에 더하는 여유 (캔버스는 붓 테두리를 조금 더 칠함) | 테스트 결과 화면보다 3~4% 넓게 셈. 0.35가 가장 정확(오차 약 1%)해서 변경 검토 중 |
| `LIVE_INTERVAL_MS` | 120ms | 그리는 중 채점 간격 (1초에 약 8번), `useSceneScoring.ts` | 채점 1회 약 9~30ms를 고려해 펜 움직임이 느려지지 않는 간격 |
